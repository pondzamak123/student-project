# เนื้อหาส่วนที่ 1: บทนำ

## 1.1 ความเป็นมาและความสำคัญของปัญหา

ในปัจจุบัน การศึกษาในระดับอุดมศึกษามีการจัดการเรียนการสอนในลักษณะโครงงาน (Project-Based Learning) มากขึ้น เพื่อให้นักศึกษาได้เรียนรู้จากการลงมือปฏิบัติจริง อย่างไรก็ดี การจัดการติดตามความคืบหน้าโครงงานของนักศึกษายังคงเป็นปัญหาที่พบได้บ่อยในหลายสถาบันการศึกษา อาจารย์ผู้ดูแลโครงงานมักต้องติดตามความคืบหน้าของนักศึกษาหลายทีมพร้อมกัน โดยใช้วิธีการสื่อสารผ่านช่องทางต่างๆ เช่น อีเมล แอปพลิเคชันแชท หรือการประชุม ซึ่งทำให้การติดตามงานขาดความต่อเนื่อง ยากต่อการประเมินผลอย่างเป็นระบบ และเกิดความล่าช้าในการให้ feedback

นอกจากนี้ การส่งงานของนักศึกษามักอยู่ในรูปแบบไฟล์เอกสารที่กระจัดกระจาย ยากต่อการรวบรวมและตรวจสอบ ส่งผลให้อาจารย์ต้องใช้เวลาในการจัดการเอกสารมากกว่าการให้คำแนะนำเชิงวิชาการ นอกจากนี้ยังขาดเครื่องมือในการแสดงภาพรวมความคืบหน้าของโครงงานทั้งหมดอย่างเป็นระบบ ทำให้การตัดสินใจและการประเมินผลทำได้ยาก

จากปัญหาดังกล่าว ทีมผู้จัดทำจึงเล็งเห็นความสำคัญในการพัฒนาระบบ "Student Project Tracking Dashboard" ซึ่งเป็นระบบเว็บแอปพลิเคชันที่ช่วยให้อาจารย์สามารถติดตามความคืบหน้าโครงงานของนักศึกษาทุกทีมได้ในหน้าเดียว พร้อมทั้งให้นักศึกษาสามารถอัปเดตความคืบหน้า ส่งรายงานรายสัปดาห์ และอัปโหลดไฟล์งานผ่านระบบได้แบบรวมศูนย์

## 1.2 วัตถุประสงค์ของโครงงาน

1. เพื่อพัฒนาระบบติดตามความคืบหน้าโครงงานนักศึกษาแบบ Real-time Dashboard
2. เพื่อให้นักศึกษาสามารถส่งรายงานสัปดาห์ (Weekly Report) และอัปโหลดไฟล์ผ่านระบบได้อย่างสะดวก
3. เพื่อให้อาจารย์สามารถให้ feedback คอมเมนต์รายงาน และเปลี่ยนสถานะโครงงานผ่านระบบได้
4. เพื่อออกแบบระบบโดยใช้ Hybrid Database (MySQL + MongoDB) ที่เหมาะสมกับลักษณะข้อมูลที่ต่างกัน
5. เพื่อพัฒนาระบบให้รองรับผู้ใช้ 3 บทบาท (Student, Teacher, Admin) พร้อม Role-Based Access Control

## 1.3 ขอบเขตของโครงงาน

**ขอบเขตด้านฟังก์ชันการทำงาน:**
- ระบบล็อกอินและยืนยันตัวตน (JWT Authentication)
- Dashboard แสดงภาพรวมโครงงานทั้งหมด
- ระบบจัดการโครงงาน (CRUD) สำหรับ Admin
- ระบบส่งรายงานสัปดาห์ (Weekly Report) สำหรับนักศึกษา
- ระบบคอมเมนต์และให้เกรดสำหรับอาจารย์
- ระบบอัปโหลดและดาวน์โหลดไฟล์
- ระบบจัดการผู้ใช้และรายวิชา (Admin)
- ระบบตั้งค่าสำหรับระบบ (System Settings)

**ขอบเขตด้านผู้ใช้งาน:**
- **Student (นักศึกษา):** ส่งรายงานสัปดาห์, อัปโหลดไฟล์, ดูความคืบหน้าโครงงานตัวเอง
- **Teacher (อาจารย์):** ดูโครงงานทีมที่ดูแล, เปลี่ยนสถานะ, คอมเมนต์รายงาน, ให้เกรด
- **Admin (ผู้ดูแลระบบ):** จัดการผู้ใช้, รายวิชา, สร้างโครงงาน, ตั้งค่าระบบ

**ขอบเขตด้านเทคโนโลยี:**
- Frontend: React 18 + Vite + TailwindCSS + Material UI
- Backend: Node.js + Express.js
- Database: MySQL (Sequelize ORM) + MongoDB (Mongoose ODM)
- Authentication: JWT (JSON Web Token)
- API Documentation: Swagger/OpenAPI

## 1.6 ประโยชน์ที่คาดว่าจะได้รับ

1. อาจารย์สามารถติดตามโครงงานนักศึกษาทุกทีมได้ในหน้าเดียว ลดเวลาในการประชุมติดตามงาน
2. นักศึกษาสามารถส่งรายงานสัปดาห์และอัปโหลดไฟล์ผ่านระบบได้อย่างเป็นระเบียบ
3. ระบบมีบันทึกประวัติการคอมเมนต์และให้เกรด ทำให้ประเมินผลได้อย่างยุติธรรม
4. การใช้ Hybrid Database (MySQL + MongoDB) เป็นแนวทางที่เหมาะสมกับข้อมูลที่มีลักษณะต่างกัน
5. ระบบสามารถขยายเพิ่มเติมได้ในอนาคต เช่น เพิ่มระบบแจ้งเตือน (Notification) หรือระบบ Grading Rubric
6. โปรเจคนี้สามารถใช้เป็นต้นแบบสำหรับการพัฒนาระบบติดตามงานในองค์กรอื่นๆ
