Dashboard แบบ Real-time ติดตามโครงงานทุกทีม
Dashboard ภาพรวม แสดงสถานะและ progress bar ของทุกโครงงานแบบ real-time
Weekly Report นักศึกษาอัปเดตทุกสัปดาห์ อาจารย์คอมเมนต์ได้ทันที
ไฟล์รวมศูนย์ อัปโหลดได้ 5 ไฟล์/ครั้ง รองรับ PDF, DOCX, PPTX
Multi-role Access นักศึกษา / อาจารย์ / Admin เห็นข้อมูลตามสิทธิ์
Hybrid Database MySQL (Users, Courses) + MongoDB (Projects, Reports)
JWT + RBAC ระบบยืนยันตัวตนและควบคุมสิทธิ์เข้าถึงทุกระดับ
